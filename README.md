# AG CORE Services Website

A beginner-friendly, responsive website for **AG CORE Services**, a data recharge business. The site helps visitors explore the services offered and contact the business through WhatsApp to make enquiries or place orders.

**Tagline:** From Skills to Opportunity.

## Services shown

- Data bundle recharge
- Airtime recharge
- VTU services
- WhatsApp order enquiries

## Built with

- **HTML5** — page structure and content
- **CSS3** — styling, layout, and responsive design
- **JavaScript** — interactive features and WhatsApp order links

## Project structure

```text
AG-CORE-Services-Website/
├── index.html       # Main webpage
├── style.css        # Website styles
├── script.js        # Interactive functionality
├── README.md        # Project documentation
└── assets/          # Logos, banners, and data-plan images
```

## Run the website locally

1. Download and extract the project ZIP file.
2. Open the extracted project folder.
3. Open `index.html` in a web browser.
4. Keep the `assets` folder in its original location so the images can load correctly.

No build tools are required to preview this static website locally.

## Customise the website

- Edit `index.html` to update text, headings, services, and contact details.
- Edit `style.css` to change colours, fonts, spacing, and layout.
- Edit `script.js` to update interactive behaviour and the WhatsApp order number.
- Replace images in `assets/` as needed. If you rename an image, update its path in the code too.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the website files, including the `assets` folder.
2. In the repository, open **Settings → Pages**.
3. Choose deployment from the `main` branch and the root (`/`) folder, then save.
4. Wait for GitHub Pages to publish the site. GitHub will show the published URL in the Pages settings.

## Important notes

- Check all data-plan prices and confirm business contact details before publishing.
- The site currently directs customers to WhatsApp for enquiries and orders.
- Online payment processing and automatic data delivery are **not** implemented.
- Do not commit passwords, private API keys, or other confidential information to a public repository.
